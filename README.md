# Week 6 Assignment: Safe Tools

This repository contains my Week 6 Python assignment about error handling using try and except.

## Files

- safe_tools.py: Contains three functions for safe division, number conversion, and dictionary lookup.
- README.md: Explains the assignment and what I learned about handling errors.

## My Reflection

An if statement can check a condition, but it does not catch the ValueError that happens when Python tries to convert "abc" into an integer. The try and except statements allow the program to handle this error and continue running without crashing.
